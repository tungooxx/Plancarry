## Tier obligations
- **T1**: Plans Don't Persist anchor; Where's the Plan? causal-localization boundary; Function-vector/generic perturbation controls represented by archived/random/unrelated controls
- **T2**: Independent untouched confirmation; no new system baselines needed if claim remains causal-localization only.
- **T3**: TransMem/generic hidden-state memory; StateBridge/latent transport if technically compatible; Memory Inception/text-derived latent/KV steering
- **T4**: Where's the Plan? distinction via first-action clamp/later branch; Function-vector/action-feature mediation controls
- **T5**: MemCompiler; ElasticMem; TransMem; Memory Inception; full KV/full residual/full plan text/matched-token summary; storage bytes/bits including global overhead
- **T6**: Second model family; second interactive environment; MemCompiler/ElasticMem system-level comparison where comparable; architecture-dependent activation-transfer literature interpreted as conditional, not universal

## Positioning
- Forbidden headline: A new latent memory method for ALFWorld agents.
- T1/T2 only: Active plan identity has a prospectively replicated causal internal component under matched observable state.
- T3-T5: A causally identified single-source plan checkpoint can be restored after interruption, persists beyond immediate steering, and is compact under honest storage accounting.
- T6 target: Causal plan-state checkpointing is a reproducible interruption mechanism across model/environment families with demonstrated long-horizon utility.

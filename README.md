# PlanCarry interruption-resumption harness

Isolated experimental harness for testing whether a compact structured task-instance carry-state preserves an LLM agent's continuation behavior after a forced context reset.

Scientific variable: post-reset memory/context representation only.
The existing `LLM/agent-scaling-llama-local` repository is a read-only reference/dependency and must not be modified by this harness.

Engineering smoke outputs are implementation evidence only, not scientific evidence.
